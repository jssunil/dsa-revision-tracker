Running in local-only mode — changes stay in this browser. Connect a GitHub repo to sync across devices and make the repo your source of truth.
Source of truth: data/progress.json in your GitHub repo · reference plan in catalog.js · images in notes-images/.

Connect GitHub

The app reads and writes data/progress.json and notes-images/ in your repo through the GitHub API. Your token is stored only in this browser.

How to create the token (60 seconds)
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access → Only select repositories → pick this repo.
  3. Permissions → Repository permissions → Contents → Read and write.
  4. Generate, copy the github_pat_… value, paste it above.

The token lives in this browser's localStorage only. It is per-device — add it again on your phone/laptop. Use “Clear token” before handing this browser to someone else. Keep the repo public so GitHub Pages serves it and note-images load.
